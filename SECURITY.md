# Política de segurança

## Versão suportada

Enquanto o projeto estiver em preparação para o lançamento, somente a branch `main` recebe correções de segurança.

## Como relatar uma vulnerabilidade

Não abra uma issue pública com detalhes exploráveis, credenciais, dados pessoais ou endereço de imóvel. Use o recurso **Report a vulnerability** na aba **Security** deste repositório. Se esse recurso estiver temporariamente indisponível, informe apenas que precisa de um canal privado, sem publicar detalhes técnicos.

Inclua no relato privado:

- impacto observado;
- rota ou componente afetado;
- passos mínimos para reprodução sem dados reais;
- logs e capturas redigidos;
- sugestão de correção, quando houver.

Credenciais expostas devem ser revogadas e rotacionadas imediatamente. Nenhuma chave real deve ser anexada ao relato.
